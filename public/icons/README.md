# Vivian SVG icons

These local SVG assets come from [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons). Keep the bundled `LICENSE` when copying or updating them.

Composer mapping: `mic` → `mic`, `micOff` → `mic-off`, `video` → `video`, `clip` → `paperclip`, `send` → `send-horizontal`. The composer displays these icons at 18px using the existing CSS mask renderer.
